Section 1: Architecture & Data Flow

Using Approach A (State-Synced WebSockets) to connect AI and Dashboard

Next.js Frontend

  • 🔄 React Context for global state
  • 🔌 Single WebSocket connection listening for:
    • chat_message
    • dashboard_sync
⟷

FastAPI Server

  • 📡 ConnectionManager (handles WS)
  • 🧠 AI Service (processes prompts)
  • 🛠️ Tools (interprets AI text into DB actions)
⟷

Database (PostgreSQL/SQLite)

  • Stored Models:
    • Tasks
    • Habits
    • Finances
    • Social
The Core Loop:
  1. You type "Log gym session" in the chat.
  2. FastAPI routes message to AI Service.
  3. AI classifies intent and triggers the `update_habit` tool function.
  4. Database is updated.
  5. FastAPI immediately broadcasts {"type": "dashboard_sync", "habits": [...]}
  6. React auto-updates the Habit Tracker block.
