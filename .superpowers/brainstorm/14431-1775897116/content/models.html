Section 2: Database & Domain Models

To support the new features, we need to expand the SQLAlchemy models in the backend

Tasks (Update)

  • id (String)
  • title (String)
  • status (pending/completed)
  • tag (habit/finance/social) - New
  • due_date (DateTime)

Habits

  • id (String)
  • name (String, e.g., "Journaling")
  • streak_count (Integer)
  • logs (JSON array of dates)

Finance / Budgets

  • id (String)
  • category (String, e.g., "Food")
  • amount_spent (Float)
  • allotted_limit (Float)
  • month (String)

Social Connections

  • id (String)
  • person_name (String)
  • last_contacted (DateTime)
  • status (overdue/done/ping)
